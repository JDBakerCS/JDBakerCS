## 📌 Featured Projects

### NORM — Normalized Ordering of Reviews and Merges

A GitHub-connected pull-request triage dashboard that imports open pull requests, evaluates their review status and code impact, and ranks a human-review queue by urgency.

NORM includes:

- React and Vite frontend
- Node.js and Express backend
- Sequelize and PostgreSQL database
- Read-only GitHub API integration through Octokit
- JWT authentication and bcrypt password hashing
- Manual synchronization and signed GitHub webhooks
- Automated backend and frontend testing

NORM does not review code, use an LLM, or write to GitHub. Its purpose is to help teams organize and prioritize human code review.

[View the NORM project](https://github.com/JDBakerCS/NORM)
